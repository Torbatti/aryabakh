bf-lab

Brainfuck interpreter × WASM JIT

Two engines for the same eight-instruction language: a tree-walking interpreter, and a compiler that emits a real WebAssembly module for the browser's own JIT to turn into x64. Run them side by side, then check their agreement with unit, integration, property, and end-to-end tests.

Libraries: lib-bf-interpreter.js, lib-bf-jit.js. Components: component-runner.js, component-tester.js. Built with Preact + htm, no bundler — open this file over a local server (module fetch is blocked on most browsers under a bare file:// URL).
